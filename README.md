# Cajero Automático en Kotlin

## Descripción
Proyecto de consola desarrollado en Kotlin para simular el funcionamiento básico de un cajero automático.

## Funcionalidades
- Consultar el saldo disponible.
- Ingresar dinero.
- Retirar dinero si hay saldo suficiente.
- Validar cantidades y opciones incorrectas.
- Salir del programa.

## Tecnologías
- Kotlin
- IntelliJ IDEA

## Ejecución
Abre el proyecto en IntelliJ IDEA y ejecuta el archivo `Main.kt`.

El saldo inicial es de **500 €**.
